Not tools. Not features. Not lines of code.

## 🎯 SECONDARY KPI

- Validated Recommendations Per Month
- Average Delta Per Cycle

---

## ⚡ THE THREE-THING RULE

Every task must improve ONE of these:

1. **Validation Speed** (faster checks)
2. **Measurement Speed** (faster delta calculation)
3. **Recommendation Quality** (better fixes)

If a task does not improve one of these three:

**DO NOT BUILD IT.**

---

## 🤖 SEVEN SPECIALIZED AGENTS

### Agent 1: Validator
**Mission:** Run comprehensive validation  
**Output:** PASS / FAIL / Regression Count  
**Speed:** <5 seconds

### Agent 2: Delta Analyst
**Mission:** Measure before/after impact  
**Output:** Delta % / Improvement Status  
**Speed:** <2 seconds

### Agent 3: Recommendation Factory
**Mission:** Generate actionable recommendations  
**Output:** Action List / Priority / Expected Delta  
**Quality:** 90%+ confidence minimum

### Agent 4: Root Cause Hunter
**Mission:** Investigate problems  
**Output:** Problem → Evidence → Top 3 Causes  
**Constraint:** ANALYZE ONLY (no fix)

### Agent 5: Framework Guardian
**Mission:** Prevent regressions  
**Output:** ALERT if regression > 0  
**Action:** STOP MERGE on regression

### Agent 6: Knowledge Curator
**Mission:** Standardize all ICs  
**Output:** Normalized data  
**Format:** problem, evidence, cause, actions, delta, confidence

### Agent 7: Throughput Officer
**Mission:** Measure factory velocity  
**Output:** Cycles/Week, Recommendations/Month, Lead Time  
**Cadence:** Daily reporting
