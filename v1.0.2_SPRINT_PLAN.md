### Phase B: Memory Leak Testing (Days 11-14)

**High-Risk Tools for Memory Leaks**:
```
collectEvidence
timeline
securityAudit
securityLogs
powershellLogs
huntPersistence
```

**Test Procedure**:
```powershell
# Baseline
$baseline = (Get-Process node).WorkingSet / 1MB
Write-Host "Baseline: ${baseline}MB"

# Run tool 50 times
for ($i = 0; $i -lt 50; $i++) {
  $result = Call-Tool "collectEvidence"
  if (-not $result.success) { break }
  
  if ($i % 10 -eq 0) {
    $current = (Get-Process node).WorkingSet / 1MB
    $delta = $current - $baseline
    Write-Host "Iteration $i: +${delta}MB"
    
    if ($delta -gt 200) {
      Write-Host "❌ LEAK DETECTED"
      break
    }
  }
}

# Final check
$final = (Get-Process node).WorkingSet / 1MB
$totalDelta = $final - $baseline
if ($totalDelta -lt 50) {
  Write-Host "✅ PASS: <50MB increase"
} else {
  Write-Host "❌ FAIL: ${totalDelta}MB increase"
}
```

**Acceptance**: Max +50MB after 50 iterations
