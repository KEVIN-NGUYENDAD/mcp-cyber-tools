## LESSONS LEARNED

### 1. Chat ID Discovery

**Lesson**: The update_id field in getUpdates is NOT the chat_id. Always use the `chat.id` field from message objects.

**Impact**: Initial misidentification delayed deployment by 1 round-trip cycle.

**Mitigation**: Created diagnostic tools to explicitly extract and validate chat IDs.

### 2. Credential File Location

**Lesson**: Multiple project paths may contain .env files. Always verify which .env is being loaded.

**Solution Implemented**: Added diagnostic logging to show exact .env path and credential source.

### 3. Unicode Encoding

**Lesson**: Vietnamese text in incident descriptions requires UTF-8 encoding. Use `open(file, encoding='utf-8')` explicitly.

**Impact**: Initial script failed on non-ASCII characters. Fixed by specifying UTF-8 codec.
